# Security Policy

Report vulnerabilities privately through GitHub Security Advisories. Workspace policy and guarantees: [zk-secops-dev/SECURITY.md](https://github.com/Darius15222/zk-secops-dev/blob/main/SECURITY.md).

This is a lab prototype, not a production authentication service.

Pull requests from branches of this repository are sent as a diff to the Gemini API for an advisory security review (`.github/workflows/ai-review.yml`, R-09). The repository is public, so the diff holds nothing that is not already published; the review is never a merge requirement.
